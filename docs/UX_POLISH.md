# QueueFlow UX Polish Guide

**Customer flow:** QR scan → clear business/branch context → service selection → issue token → show private lookup key → live progress and estimated wait → optional turn alerts.

**Staff workspace:** keep active ticket and primary action prominent, queue controls predictable, status changes reversible only when permitted, and shortcuts accessible via keyboard.

**Super Admin:** show platform KPIs first; progressively reveal account, business, audit and security detail.

**Accessibility:** semantic labels, visible focus, minimum 44px touch targets, error feedback near controls, live status announcements, contrast that does not rely on color alone, reduced-motion support.

**Responsive:** prioritize 320–430px customer view; allow wide admin tables to scroll or adapt into cards; avoid hidden controls on mobile.
